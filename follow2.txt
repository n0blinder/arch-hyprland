=========================================================

=========================================================
SECTION 12 - greetd Login Manager Service
=========================================================

Install:

greetd
greetd-tuigreet


Disable existing display manager if present:


Example:

sudo systemctl disable --now sddm.service


Copy greetd configuration:

Repository:

greetd/config.toml


Replace:

/etc/greetd/config.toml


Command:


sudo cp greetd/config.toml /etc/greetd/config.toml


Enable greetd:


sudo systemctl enable greetd.service


Start greetd:


sudo systemctl start greetd.service


Verify:


systemctl status greetd.service


=========================================================
SECTION 13 - Create vtrgb Console Color Service
=========================================================

Purpose:

Apply custom TTY color palette before greetd/tuigreet loads.


Repository file:

vtrgb


This file is a systemd service unit.


Copy service file:


sudo cp vtrgb \
/etc/systemd/system/vtrgb.service


Reload systemd units:


sudo systemctl daemon-reload


Enable service:


sudo systemctl enable vtrgb.service


Start service:


sudo systemctl start vtrgb.service


Verify:


systemctl status vtrgb.service


Expected:

TTY colors are applied before the greetd login screen appears.


=========================================================
SECTION 14 - Systemd Service Final Reload
=========================================================

After installing all custom services:


sudo systemctl daemon-reload


List enabled custom services:


systemctl list-unit-files --state=enabled


Expected enabled services:


bluetooth.service

auto-cpufreq.service

greetd.service

vtrgb.service


User services:


hyprpolkitagent.service

SECTION 20 - NVIDIA GPU Setup
=========================================================


This section applies only to systems containing Nvidia GPU.


Install:

nvidia-utils

lib32-nvidia-utils

egl-wayland

linux-headers


After installation:


Regenerate initramfs:


sudo mkinitcpio -P


Enable Nvidia DRM modeset:


Verify:


cat /sys/module/nvidia_drm/parameters/modeset


Expected:

Y


Reboot:


sudo reboot


Verification:


nvidia-smi


Check modules:


lsmod | grep nvidia
